# Claude Code Heihei v1.6.1

**让协作任务闭环可见、可续接**：新增桌面端协作任务面板与 compact 后协作上下文续接，补齐并行派活的台账状态闭环，并强化项目路径一致性、协议预算门禁与依赖安全更新。

## 协作任务面板

- 新增桌面端协作任务台账面板：按当前活动会话项目筛选任务，支持进行中/已结束/全部过滤、任务详情查看、复制任务 ID 与交付路径；通过任务事件同步并支持离线缓存展示。实现：`desktop/src/pages/CollabTasks.tsx:34-105,116-165`、`desktop/src/stores/collabTaskStore.ts:85-123,132-172`；存储行为测试：`desktop/src/stores/collabTaskStore.test.ts:97-136,162-210`。
- 面板仅桌面运行时提供入口。无活动会话且无项目目录时不查询台账任务列表、不猜项目目录，直接显示空态；仍会发起 `whoami` 探活判定连接状态，服务未就绪时显示遮罩与重连提示。实现：`desktop/src/components/layout/TabBar.tsx:277-280`、`desktop/src/pages/CollabTasks.tsx:71-95,143-165`、`desktop/src/stores/collabTaskStore.ts:125-127,169-171`。移动浏览器的非会话页签会回到已有会话或空白/对话入口：`desktop/src/components/layout/AppShell.tsx:180-189`；测试：`desktop/src/components/layout/AppShell.test.tsx:449-464`。

## 协作上下文续接与员工免等待

- compact 后为协作会话注入协作上下文卡片；内容按主管/员工角色裁剪，可含规则摘要、花名册、任务概览及员工当前任务信息。`CC_HEIHEI_COLLAB_CONTINUATION` 默认启用，设为 `0` 时关闭；普通会话与关闭开关时不探活、不发请求、不注入。接入点：`src/services/compact/compact.ts:564-579,960-975`；实现：`src/collaboration/collabContextAttachment.ts:282-345`；测试：`src/collaboration/collabContextAttachment.test.ts:48-123`、`src/services/compact/compact.test.ts:70-90`。 
- 员工会话默认不注入可能等待人工答复的工具（`AskUserQuestion`、`EnterPlanMode`、`ExitPlanMode`、`ReviewArtifact`）。`CC_HEIHEI_SERVANT_NONINTERACTIVE` 默认 `1`；设为 `0` 可恢复这些工具并关闭自动拒绝兜底。实现：`src/collaboration/collabToolContract.ts:169-191`、`src/tools.ts:184-193,332-341`；角色与开关测试：`src/server/__tests__/collab-cli-tools.test.ts:279-329`。

## 台账补推进与误投防护

- 员工会话开工信号按会话推进任务状态；`accepted` / `in_progress` 不精确对应单条任务。员工忙碌期间连派的任务可能在汇报时从 `dispatched` 一次性补推进到 `delivered`；history 前两条固定 note「汇报时补推进：回合中途入队未收到开工信号」、`by: system`，三条共用汇报时刻，只推送最终态一次。服务端实现：`src/server/services/collabTaskService.ts:471-519,527-582,643-694`；测试：`src/server/__tests__/collab-task-service.test.ts:210-238,355-401`。
- 面板状态徽标可能从「待接单」直接跳至「已交付」；补推进 note 保存在任务 history，面板详情不渲染一般 history 条目，因此不会显示该 note。依据：`desktop/src/pages/CollabTasks.tsx:15-24,169-183,188-205`。
- 汇报误投防护按任务归属校验 HTTP 改投与信箱台账推进；误抄他人 `taskId` 不会推进他人任务，汇报消息仍会投递，并按既有规则兜底解析目标。请使用派活页脚的 `taskId`。实现/测试：`src/server/services/reportTargetResolver.ts:115-170,208-227`、`src/server/__tests__/report-target-resolver.test.ts:103-146,224-270`、`src/server/services/dispatchMailboxService.ts:382-424`、`src/server/__tests__/dispatch-mailbox.test.ts:238-350`。

## 已知限制与行为说明

- `accepted` / `in_progress` 是员工会话级开工信号，不是单任务精确开工证明；员工忙碌期间收到的任务可能保持 `dispatched`，在汇报时再补推进。补推进 history 有三条共用汇报时刻的记录，前两条固定 note 并以 `by: system` 标识，通知只推送最终态。实现/测试：`src/server/services/collabTaskService.ts:471-519,527-582,643-694`、`src/server/__tests__/collab-task-service.test.ts:210-238,355-401`。
- **面板与台账分层**：面板状态徽标可能从「待接单」直接跳至「已交付」；台账 history 记录补推进说明，但面板详情不渲染一般 history 条目，因此不会显示该说明。依据：`desktop/src/pages/CollabTasks.tsx:15-24,169-183,188-205`；history 测试：`src/server/__tests__/collab-task-service.test.ts:355-401`。
- 任务面板仅桌面端；无活动会话/项目目录时显示空态且不请求台账列表或猜测目录，但仍会发起 `whoami` 探活以判定连接状态。服务未就绪时显示磨砂遮罩与重连提示。实现：`desktop/src/components/layout/TabBar.tsx:277-280`、`desktop/src/pages/CollabTasks.tsx:71-95,143-165`、`desktop/src/stores/collabTaskStore.ts:125-127,169-171`。移动端非会话页签回退：`desktop/src/components/layout/AppShell.tsx:180-189`；测试：`desktop/src/components/layout/AppShell.test.tsx:449-464`。
- `GET /api/collab-tasks` 不带 `project` 或 `forSessionId` 时返回所有项目任务，`projectDir` 为 `null`；该行为为既有行为。实现/测试：`src/server/api/collabTasks.ts:68-90`、`src/server/__tests__/collab-tasks-api.test.ts:364-377`。
- 新 CLI 与缺少台账能力的旧服务端混装不属于支持场景；`broadcastId` 幂等仅保证单进程内；对终态任务再提交 `rework` 返回 `409`，要继续返工需重新派活。测试：`src/server/__tests__/collab-cli-tools.test.ts:401-409,560-634,683-690`、`src/server/__tests__/servants.test.ts:1211-1355`、`src/server/__tests__/collab-task-service.test.ts:85-105`。
- 会话上下文续接可通过 `CC_HEIHEI_COLLAB_CONTINUATION=0` 关闭（默认开启）；`CC_HEIHEI_SERVANT_NONINTERACTIVE` 默认 `1`，设为 `0` 可关闭员工无人可审批时的自动拒绝并恢复人工等待工具。实现/测试：`src/collaboration/collabContextAttachment.ts:282-295`、`src/collaboration/collabContextAttachment.test.ts:48-62`、`src/collaboration/collabToolContract.ts:169-191`、`src/server/__tests__/collab-cli-tools.test.ts:279-329`。
