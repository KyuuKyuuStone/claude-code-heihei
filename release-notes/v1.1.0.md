# Claude Code Heihei v1.1.0

多会话协作的第一个大版本：**员工可感知、可管理、可自愈**。围绕 09-10 两份实战反馈的 Top 问题，把协作编排从"可用"推进到"放心跑长任务"。

## 协作体验

- **员工状态灯**：侧边栏员工会话显示实时状态——忙碌（绿）/ 疑似卡死（黄，运行中但 10 分钟无活动）/ 空闲（灰），卡死一眼可见。
- **唤醒按钮**：右键员工会话 → 「唤醒员工（中断并注入续跑提示）」——中断卡死的会话并自动注入续跑指引（实战验证的救活方式，现在是一键操作）。
- **主管广播按钮**：右键主管会话 → 「广播到本项目员工…」，一条消息发给本项目全部员工（停工、需求变更等场景）。
- **派活撞车提醒**：派活响应携带目标会话忙闲状态（运行中且 3 分钟内有活动 = 忙），主管 AI 可据此决定排队或改派。

## 可靠性

- **员工报错自动续跑**：员工轮次因 API 抖动/错误中断时，自动注入续跑提示（含错误摘要），连续 2 轮后升级——通知主管人工介入并停止自动重试，任何一轮成功即重置。线上模型员工的中断不再需要人工发现和手动救活。
- **员工崩溃自动上报**：员工 CLI 进程异常崩溃时，主管会话自动收到系统消息（角色、退出码、处理建议）。
- **员工假死自动重推**：运行中但 10 分钟无活动的员工会话被自动重推（最多 3 次），仍无活动则升级通知主管。
- **只读观察约束档位**：协作设置新增「约束档位」——完全执行 / 只读观察（禁改文件，信箱汇报放行）。给分析型员工或高信任要求场景提供安全边界。

## 工具可发现性

- **ToolSearch 关键词搜索兜底**：deferred 工具搜索为空时自动回扫全量工具集——个别会话"关键词搜不到工具"时不再空手而归（`select:` 精确加载提示保留）。
- **诊断探针**：deferred 集合异常小时在调试日志留证据，为根因调查采集数据。

## 工程质量

- **CI 新增服务端测试门禁**：`bun test src/server`（78 个测试文件）进入 CI——核心协作代码的回归从此有自动防护。
- 修复 Windows 上 doctor 路径断言测试失败（测试自身的分隔符 bug）；诊断 stderr 可见性测试超时余量放宽至 30 秒。

## 升级说明

- 无破坏性变更。已保存的协作方案、花名册、会话数据完全兼容。
- 只读观察档位的约束在员工会话启动时生效；已在运行的员工需重新派活或重启该会话后生效。
