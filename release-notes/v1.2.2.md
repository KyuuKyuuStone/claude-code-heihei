# Claude Code Heihei v1.2.2

降噪补丁：修复 v1.2.1 发布后实测发现的**「待命会话被假死重推循环戳」**问题。

## 修复

- **待命会话不再被误判为卡死**：此前的重推判定只看"无活动时长"，导致已经**正常结束回合、处于待命**的会话也会被当作疑似卡死反复重推。而每次重推都会让会话产生一次回复（回复本身就是活动），活动又重置计时，于是形成 **戳 → 回复 → 重置 → 再 10 分钟 → 再戳** 的循环，**每轮白白消耗一个模型回合**。
- **重推条件收紧为「回合进行中 + 10 分钟无活动」**：
  - 回合已正常结束的**待命会话不再被打扰**；
  - **真·卡死（回合中确实卡住）仍会被自动重推**，自愈能力不受影响。
- **状态同源不漂移**：降噪判定复用**派活回执**已有的回合态观察，不引入第二套状态来源，避免两处判定随时间各说各话。

## 升级说明

- 无破坏性变更。从 v1.2.1 直接检查更新即可升级。
- 仅影响重推触发条件；自动重推的既有行为（告警策略、重推上限）保持不变。
