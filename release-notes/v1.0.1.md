# Claude Code Heihei v1.0.1

本版本在 v1.0.0 基础上新增了 **本地大模型** 支持：无需联网、无需 API Key，直接在本机运行 GGUF 模型，适合普通学生电脑。

## 新增：本地模型

- **本机运行 GGUF 大模型**：直接用内置的 `llama.cpp` 引擎跑 `.gguf` 模型文件，离线可用、不消耗 API 额度。
- **自动识别硬件**：检测 CPU 核数、内存与 GPU（Vulkan，跨 NVIDIA / AMD / Intel），按硬件推荐「低配 / 中配 / 高配 / 超级 / 帝王」配置档位。
- **一键跑分**：设置目标生成速度 + 上下文长度 + 硬件使用率，程序实测出能达到目标速度的最小资源占用档位，并估算 KV 缓存是否装得下显存。
- **配置方案**：一套方案 = 模型文件 + 配置档位 + 细节参数（上下文窗口、CPU 线程、GPU 层数、批处理、KV cache 类型、Flash Attention、采样参数），保存后可随时应用。
- **下载模型中心**：汇总 Hugging Face / ModelScope / Ollama / LM Studio 等 GGUF 下载网站（跳转 + 一句话介绍），附推荐模型清单与「拿到 GGUF 后怎么用」分步说明。
- **会话语义切换**：在会话输入框左下角切换成本地模型，即可离线使用。

## 说明

- 本地推理内核（llama.cpp）已升级到 b10686。
- 跑分数据只对当次内核版本有效，更新内核后建议重新跑分。

## 安装

请在本页面底部 Assets 中下载对应平台和架构的安装包：

- macOS：`Claude-Code-Heihei-1.0.1-mac-arm64.dmg` / `Claude-Code-Heihei-1.0.1-mac-x64.dmg`
- Windows：`Claude-Code-Heihei-1.0.1-win-x64.exe` / `Claude-Code-Heihei-1.0.1-win-arm64.exe`
- Linux x64：AppImage、deb 或 `Claude-Code-Heihei-1.0.1-linux-x86_64.rpm`
- Linux ARM64：AppImage、deb 或 `Claude-Code-Heihei-1.0.1-linux-aarch64.rpm`
