# Claude Code Heihei v1.0.0

这是 **Claude Code Heihei** 的首个正式版本（1.0）。它是一个桌面端 Claude Code 工作台，并在会话工作台之上新增了「会话级上下级协作」能力：把多个会话组织成「主管—员工」的协作关系，主管一键派活，员工会话无人值守自动执行并汇报，主管验收后继续安排或向用户交付。

## 核心能力

- **会话工作台**：会话、多项目、分支 / Worktree、工作区改动与 Diff 审阅、权限审批、模型配置、Computer Use、H5 远程访问、IM 接入、定时任务与用量统计，集中到一个 macOS / Windows / Linux 应用里。
- **会话级上下级协作**：把任意会话任命为「主管」（每项目唯一），或登记为「员工」（角色与特性自由定义，如后端 / 前端 / 写作 / 绘画师）。主管向员工会话派活，员工会话无人值守自动执行，完工后用一条命令汇报；主管验收后继续派活或交付。
- **项目隔离**：花名册与派活都按工作目录隔离，跨项目派活会被服务端直接拒绝（409）。
- **多服务商**：Claude / ChatGPT / Grok 官方账号可直接登录；DeepSeek、Kimi、智谱 GLM 等第三方 API 有现成预设；也支持 LM Studio、Ollama 本地模型。
- **六套配色主题**：纯白、纸墨、经典暖色、青瓷、墨夜、墨夜蓝，可跟随系统深浅色自动切换。

## 安装

请在本页面底部 Assets 中下载对应平台和架构的安装包：

- macOS：`Claude-Code-Heihei-1.0.0-mac-arm64.dmg` / `Claude-Code-Heihei-1.0.0-mac-x64.dmg`
- Windows：`Claude-Code-Heihei-1.0.0-win-x64.exe` / `Claude-Code-Heihei-1.0.0-win-arm64.exe`
- Linux x64：AppImage、deb 或 `Claude-Code-Heihei-1.0.0-linux-x86_64.rpm`
- Linux ARM64：AppImage、deb 或 `Claude-Code-Heihei-1.0.0-linux-aarch64.rpm`
