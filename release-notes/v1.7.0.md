# Claude Code Heihei v1.7.0

**更好懂、更耐等的日常版**：报错提示改成中文人话、协作通知消息默认折叠、默认超时从 120 秒提升到 320 秒、会话启动加上总超时兜底；另修掉几个会真实撞上的问题。本版以一次大规模内部结构重排为主，界面功能保持稳定。

## 错误提示更易懂

- **不再直接显示英文技术串**。此前出错时详情里会出现原始的英文报错（例如 `Request timed out after 120s`），现在按类型显示中文提示：超时→「服务暂时无响应，请稍后重试」；连不上→「无法连接本地后台服务」；服务端错误→「服务返回错误，请稍后重试」。有信息量的业务错误仍原样显示，不做翻译。**五种界面语言同步**。
- **等待期有反馈**：首屏加载超过 **3 秒**时显示「加载较慢，请稍候…」，不再只是「加载中」。
- **修正一处误导性提示**：连接失败时的旧文案是「无法连接本地服务，请确认应用仍在运行」；由于桌面端是「窗口 + 后台服务」分离的结构，连不上通常是后台服务不可达、窗口本身正常，旧文案会让人误以为软件没开。新文案改为「**无法连接本地后台服务**」，五种界面语言同步。

## 协作通知消息默认折叠

- **改动原因**：多会话协作时，会话之间互发的通知消息（任务派发与完工汇报）此前是长篇纯文本，直接铺在对话里占好几屏。
- **改后**：这类通知**默认折叠成一行卡片**——显示摘要首句、来源图标、徽标、任务号（可点按复制）与相对时间，点击即可展开或收起。
- **不会被误折叠**：你自己输入的消息、助手回复、以及正在流式输出的消息都不会折叠。仅识别末尾带系统页脚的协作通知。
- 派发侧与汇报侧**两侧都折叠**（服务端会为汇报补充可识别的页脚）。**五种界面语言同步**。

## 更长的默认超时，减少长任务被中途掐断

- **默认请求超时 120 秒 → 320 秒**：对话与会话类未单独指定超时的请求全部适用，减少对话中出现 120 秒超时。
- **命令执行的默认单命令超时 120 秒 → 320 秒**：此前较长命令会在对话里显示 `Command timed out after 2m 0s`。显式指定超时的命令不受影响；单项上限仍为 **600 秒**。
- **说明**：320 秒只是把「放弃等待」的门限拉长，**不改变失败率**——卡死时仍会失败，只是错误出现得更晚；配合上面的「加载较慢」提示，等待期不再是静默的。

## 会话启动超时兜底

- **改前**：拉起一个会话由多个各自限时的子步骤组成，但整条链路没有总预算，长尾可累计到分钟级，导致会话列表请求被长时间拖住。
- **改后**：整条启动链路加 **180 秒总超时**，超时后不再无限期等待（内部仍按原有路径收尾，不影响已进行的步骤）。

## 修复的问题

- **会话列表一度显示「目录缺失」、消息接口返回 500**：在上一个测试包（1.7.0-test.1）中，侧栏每个会话都显示「目录缺失」，会话消息接口报错。根因是内部结构重排时一处文件读写接口用错了导入形式，已修复。
- **一处汇报消息的自动恢复链路失效**：网络失败时，协作汇报的「自动重连」与「降级写入信箱」两条兜底同时失效，导致汇报可能直接报错。已修复，两条自愈路径恢复。
- **误导性的联网提示文案**：见上文「错误提示更易懂」。
- 另修复了界面报错未按类型映射的问题，以及个别模块的类型错误（其中一处是重排过程中被漏掉的函数，已原样补回）。

## 已知限制与未验证项

- **本版未运行任何自动化测试套件**（遵循既定的禁测约定；单次运行测试会占用大量内存）。所有改动为**静态验证 + 针对性冒烟**，**未经完整功能测试**。
- 本版主体是一次大规模**内部代码结构重排**（把最大的几个代码文件拆分成更小的模块，纯搬迁、不改行为）。这类重排「静态全绿、真跑起来仍可能出问题」的风险已被上一测试包的「目录缺失」事故验证过，因此更依赖实际使用来暴露问题。
- **如需保守，可回退到 1.6.1**：如遇到异常，退回上一正式版本即可恢复。
- 界面行为、协作通知折叠的真机渲染等**未经端到端实测**（未验证）。

## 升级说明

- 通过应用内「检查更新」即可升级（`latest.yml` + blockmap 支持增量下载）；也可重新下载最新安装包覆盖安装。
- 启动后调用 `GET /api/whoami` 可查看当前运行版本号（返回 `app`、`version`、`pid`、`startedAt`）。
- 建议桌面应用与其命令行组件使用同一版本，以获得完整能力。
