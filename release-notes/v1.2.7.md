# Claude Code Heihei v1.2.7

三处实测反馈修复：员工状态灯不再"假转圈"、会话掉线不再刷「Session not found」、CLI 静默退出不再无从查起。

## 修复

- **员工列表转圈图标残留**：员工回合已结束、实际处于待命时，列表状态灯偶发停留在"忙碌转圈"。根因是服务端的回合状态字段在回合结束时未正确复位。本次采用**两步事件驱动方案**：回合状态的翻转改由「回合开始 / 回合结束」两个事件各自驱动，`turnInProgress` 在回合结束时必然归位；界面状态灯按真实回合态渲染。已修复——**待命就是待命，转圈只在真的干活时出现**。
- **「Session not found」轮询刷屏**：会话已被移除或进程退出后，界面仍在反复轮询并弹「Session not found」错误刷屏。现在客户端会**记住"该会话已不存在"**，立即停止对它的轮询，界面安静下来。
- **CLI 静默退出可查证**：此前 CLI 进程悄悄退出（如崩溃）时几乎没有线索可查。现在这类退出会**写入明确的诊断记录**（含退出原因标记），排查时不再无从下手。

## 升级说明

- 无破坏性变更；从 v1.2.6 直接检查更新即可升级。
- 修复均为行为纠偏，不改变任何功能的使用方式。
