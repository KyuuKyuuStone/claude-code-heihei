# Claude Code Heihei v1.0.2

本版本重点重做了**本地模型**：更诚实（实测说话）、更快（长对话提速）、更好上手（精选模型清单 + 能力标注），并删除了桌面宠物功能。

## 本地模型大改版

### 跑分更诚实

- **GPU 真探测**：启动和跑分前实跑一次 GPU 推理，跑得动才用 GPU。GTX 750 这类老显卡不再「启动成功但一说话就崩」（`ErrorDeviceLost`），会自动退回纯 CPU 并在日志里说明。
- **运行方式结论**：跑分完成后直接告诉你本机采用**纯 CPU / GPU 全量 / GPU+CPU 混合**哪种方式，不再让你猜。
- **67% / 100% 两档实测**，每档测 2 次取平均降噪，推荐最快的一档。
- **首字延迟预估**：Claude Code 每次请求带约 30K 提示词，报告按实测速度折算「第一句话要等多久」，提前管理预期。
- **上下文按内存规划**：不再写死 32K——f16 KV 缓存装不下时自动换 **q8_0**（省一半内存、质量损失极小），还不够才降上下文长度。
- 修复跑分弹窗报 `Invalid Electron IPC payload` 的问题。

### 配置方案更省心

- **配置档位（低配~帝王）已移除**：新建方案按你的硬件自动填参数起点（67% 线程甜点比例、无独显直接纯 CPU），跑分结果一键应用，方案参数与实测完全一致。
- **启动失败自动降档**：显存/内存装不下时自动重试（GPU 退 CPU → 上下文砍半），不再甩报错。
- **状态卡显示实际 GPU 分层**（如 `GPU 分层 33/37`）。
- **长对话 KV 复用**默认开启（`--cache-reuse`），长会话每轮不再重算整个历史，明显提速。

### 多模态与进阶

- **支持看图**：多模态模型（gemma-3-4b、Qwen-VL 等）可在方案里配置 **mmproj 视觉投影文件**，配好即可识别图片。
- **自定义引擎目录**：N 卡用户可外接 llama.cpp 官方 CUDA 版引擎（体积大不随应用打包，下载中心有指引）。
- **能力档标注**：按模型参数规模标注「适合聊天 · 轻任务 / 能扛工具调用 / 能看图」，选模型不再抓瞎。
- **精选模型清单**：下载中心内置 5 款官方模型推荐（Qwen3-4B、Qwen2.5-Coder-7B、Qwen3-8B、gemma-3-4b-it、R1-Distill-7B），附能力说明与 Hugging Face / ModelScope 直链。
- **进阶参数**：投机解码草稿模型（生成提速 1.5~3 倍）、MoE 专家权重 CPU 分层。

## 其他

- **删除桌面宠物功能**：应用更聚焦、体积更小。
