# Claude Code Heihei v1.1.1

修复 v1.1.0 员工状态灯的两个问题：**状态点一直灰色不变化**（花名册数据从不刷新），以及状态语义不诚实（把"待命"误标为"疑似卡死"）。

## 员工状态灯修复

- **花名册 20 秒轮询刷新**：此前花名册数据只在应用启动时获取一次——员工实际被拉起干活后，侧边栏的状态数据仍是启动时的旧快照，状态点永远灰色。现在每 20 秒自动刷新，状态实时变化。
- **状态语义修正**（三态）：
  - 🟢 **忙碌**：员工 CLI 运行中且最近 3 分钟有 transcript 活动（正在干活）
  - ⚪ **待命**：员工 CLI 运行中但无近期活动（回合结束，等待下一个任务——不是卡死）
  - ⚫ **未运行**：员工 CLI 未拉起
- 卡死判定收敛到服务端假死 watcher（10 分钟阈值自动重推），状态灯只负责如实呈现。

## 升级说明

- 无破坏性变更。从 v1.1.0 直接检查更新即可升级。
