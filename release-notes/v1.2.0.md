# Claude Code Heihei v1.2.0

协作安全与可靠性的一轮加固：新增**目录白名单**约束档，给员工会话划出可写的边界；工具调用出现异常模式时**自动熔断并通知主管**；文件信箱补上**周期兜底扫描**，消除 watcher 静默失效；界面补上员工忙碌态反馈。另含两项工程质量改进。

## 协作安全

- **「目录白名单」约束档（新档位）**：在原有「完全执行 / 只读观察」之外，新增按目录放行的约束档——**仅白名单目录内的文件工具可写**，白名单之外的写入被拒绝。适合让员工在指定子目录内作业、又不希望它动到仓库其他位置的场景。
  - **边界已明示**：该档位约束的是**文件工具**的写入路径；**Bash 不受此约束**（Bash 能做什么仍取决于现有的命令权限模型）。请按此边界决定是否启用。

## 协作可靠性

- **连续调用不存在工具自动熔断（新）**：员工会话连续调用不存在的工具时，不再无限重试空转——达到阈值后**自动熔断，并通知主管**，避免会话在错误路径上持续消耗配额与时间。
- **文件信箱 watcher 周期兜底扫描**：文件信箱此前依赖 `fs.watch` 事件驱动，一旦 watcher 未建立或事后失效，投递的文件会**静默不被消费**（2026-09-14 实战：派活文件 40+ 秒无响应、无错误提示）。现在增加**周期兜底扫描**（默认 45 秒），并顺带重建缺失的 watcher——最坏一个周期内文件仍会被消费。

## 界面

- **员工忙碌态转圈动画**：员工会话处于忙碌状态时显示转圈反馈，长任务执行期间的状态一眼可见。

## 工程质量

- **CI 新增桌面测试门禁 job**：桌面端测试进入 CI 门禁，桌面回归从此有自动防护（此前仅服务端测试有门禁）。
- **协作测试环境隔离修复**：修正协作相关测试的环境隔离问题，消除测试间的相互影响。

## 升级说明

- 无破坏性变更。从 v1.1.2 直接检查更新即可升级。
- 已保存的协作方案、花名册、会话数据完全兼容。
- 目录白名单档位为**新增**档位，不影响既有档位的行为；已运行的员工需重新派活或重启该会话后生效。
