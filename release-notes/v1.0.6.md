# Claude Code Heihei v1.0.6

本版本补齐**协作会话的管理与可发现性**：中断运行有了正式端点、端点名录不再靠猜、广播一键可达——全部源自 UE5 项目三天多会话实战反馈。

## 新增能力

- **中断运行端点**：`POST /api/sessions/:id/interrupt`——中断会话当前运行（SDK 优雅中断 + 3 秒强杀兜底），保留会话与历史。此前主管想停掉空转的员工会话只能误用 DELETE（连历史一起删，不可逆）。
- **端点名录**：`GET /api` 一次返回协作与会话管理的全部可用端点及用法说明——主管 AI 不用再穷举猜路径。
- **主管广播**：`POST /api/session-messages` 的 body 用 `{"broadcast":true,"content":"...","fromSessionId":"..."}`，一条消息发给本项目全部员工（"停工"、统一约定变更等场景）。
- **登记消息防呆**：新员工加入的系统通知现在附带其会话 ID 与工作目录——若花名册按项目隔离查不到它，一眼能核对是目录不同而非登记丢失。

## 技能与协议同步

- work-orchestrator 协议新增「员工管理」章节：修改角色特性/禁用员工用 **PUT**（不是 PATCH）、中断用 interrupt、广播用法、名录查询——均为实战反馈中"靠猜"的用法。

## 升级说明

- 无破坏性变更，完全向后兼容。
