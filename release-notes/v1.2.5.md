# Claude Code Heihei v1.2.5

修好主管上任时的 onboarding 空窗，并把三块**从未接线**的半成品彻底请出代码库。

## Onboarding 修复

- **主管上岗消息补花名册兜底**：主管往往是最先被拉起的会话，员工会话创建在其后 78~193 秒。此前主管上任时读到的花名册常为空或不完整，导致后续编排踩空。现在上岗消息会在**花名册为空 / 明显不全时等 60 秒重查（最多 5 次）**。
- **花名册 `forSession` 自排除请求者**：查询结果不再包含发起者自己，**防止主管把自己当作员工派活**。
- **员工会话标题按角色生成**：新会话自动带上角色标题（走 custom-title）；**只对新会话生效，不覆盖用户已命名**，失败也不阻断登记。
- **`GET /api`（无斜杠）修复**：此前与 `/api/` 行为不一致；现在两者返回同一份 JSON 端点名录，并新增路由测试锁住两条路径。

## 移除「未接线三特性」

以下三块经核查为**初始快照自带的未接线半成品**，经用户拍板「都不要，干净删掉」，本次一并移除：

- **H5 设置区**：含服务端 h5 栈与**浏览器运行时残留**（H5 令牌门、`H5ConnectionView`、AppShell 渲染分支）。
- **官方 provider 登录卡片**：Claude / ChatGPT / Grok 三套登录组件与对应 OAuth store。
- **cc-switch 导入**。

**规模**：25 个文件删除 + i18n 约 249 键 × 5 语言清理，**净删约 1.05 万行**。

**保留**：通用「本机受信 vs 远程」判定（`localRequestPolicy.ts`，非本机仍被拒）与**官方 provider 的运行时鉴权服务**（登录入口没了，但已有凭据的运行时调用链路仍在用，未受影响）。

## 行为变化（三则）

1. **固定端口配置不再生效**：`h5Access.fixedPort` 随 H5 设置区一并移除，端口回退为 **sticky（沿用上次端口）**。
2. **断连宽限不再可配**：原值存在 H5 设置中，现已固定为 **30 秒**。
3. **远程浏览器访问随 H5 特性终结**：浏览器客户端不再经由 H5 通道；在 explicit-auth 部署下，**远程 CORS 预检亦被拒绝**（远程访问需按通用鉴权处理）。

## 升级说明

- 无破坏性变更（被移除的三特性均未接线，正常使用路径不受影响）。
- 若你此前**依赖 H5 远程访问**，本次升级后该通道不再可用——这是有意移除，不是故障。
- 若曾配置 `h5Access.fixedPort`，升级后该配置被忽略，端口按 sticky 规则回落。
