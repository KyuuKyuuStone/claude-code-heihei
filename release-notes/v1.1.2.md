# Claude Code Heihei v1.1.2

修复实战事故 Top1 根因（ToolSearch 被误用）、把桌面端测试基线清零，并修掉 Sidebar 的主题适配缺陷。本版以"消除误导"和"消除噪声"为主，无新功能。

## ToolSearch 误用修复（实战事故 Top1 根因）

实战复盘发现：工具搜索的失败大多不是搜不到，而是**文案与语义把模型带偏**——模型据此误判"没有这个工具"，转而去手工拼命令或放弃。本版从提示层与回执层同时收口：

- **核心工具恒 inline 说明**：核心工具始终以内联方式声明，不再依赖模型自行搜索发现，从源头消除"核心工具搜不到"的错觉。
- **`select:` 命中显式回执**：精确加载命中时返回明确回执，模型能确认"工具确实已加载"，不再因沉默响应而误判为失败。
- **协作侧文案同步**：协作相关的 4 处提示文案修正，并完成简中 / 繁中 / 英 / 日 / 韩**五语言同步**，避免非中文语境下继续复现同一误导。

## 桌面测试基线清零

- 历史遗留的失败基线由 **14 个失败文件 / 40 个失败用例全部清零**，桌面端 vitest 恢复"全绿即真绿"的可信状态。
- 其中 **25 条** 与 H5 接入 / 官方卡片 / cc-switch 相关的用例暂**显式豁免**（标注待接线），待对应功能接线后恢复断言——豁免是显式的，不会掩盖真实回归。
